═══════════════════════════════════════════════════════════════════════════════
1. USERS TABLE
═══════════════════════════════════════════════════════════════════════════════
users
├── id (UUID) PRIMARY KEY
├── email (VARCHAR(255)) UNIQUE NOT NULL
├── password_hash (VARCHAR(255)) NOT NULL
├── name (VARCHAR(255)) NOT NULL
├── role (VARCHAR(50)) NOT NULL CHECK IN ('USER', 'ADMIN')
├── status (VARCHAR(50)) NOT NULL CHECK IN ('ACTIVE', 'INACTIVE')
├── created_at (TIMESTAMP) NOT NULL
├── updated_at (TIMESTAMP) NOT NULL
└── last_login_at (TIMESTAMP)

Indexes:
- idx_users_email ON (email)
- idx_users_status ON (status)

═══════════════════════════════════════════════════════════════════════════════
2. USER_SESSIONS TABLE (Refresh Tokens)
═══════════════════════════════════════════════════════════════════════════════
user_sessions
├── id (UUID) PRIMARY KEY
├── user_id (UUID) NOT NULL → REFERENCES users(id) ON DELETE CASCADE
├── refresh_token (TEXT) NOT NULL
├── device_info (JSONB)
├── expires_at (TIMESTAMP) NOT NULL
└── created_at (TIMESTAMP) NOT NULL

Indexes:
- idx_sessions_user ON (user_id)
- idx_sessions_token ON (refresh_token)
- idx_sessions_expires ON (expires_at)

═══════════════════════════════════════════════════════════════════════════════
3. DOCUMENTS TABLE
═══════════════════════════════════════════════════════════════════════════════
documents
├── id (UUID) PRIMARY KEY
├── user_id (UUID) NOT NULL → REFERENCES users(id) ON DELETE CASCADE
├── name (VARCHAR(255)) NOT NULL
├── type (VARCHAR(50)) NOT NULL CHECK IN ('PDF', 'DOCX', 'TXT')
├── size (BIGINT) NOT NULL
├── status (VARCHAR(50)) NOT NULL CHECK IN ('PROCESSING', 'INDEXED', 'FAILED')
├── chunks_count (INTEGER) DEFAULT 0
├── storage_path (TEXT) NOT NULL
├── summary (TEXT)
├── tags (TEXT[])
├── upload_started_at (TIMESTAMP) NOT NULL
├── indexed_at (TIMESTAMP)
├── created_at (TIMESTAMP) NOT NULL
└── updated_at (TIMESTAMP) NOT NULL

Indexes:
- idx_documents_user ON (user_id)
- idx_documents_status ON (status)
- idx_documents_created_at ON (created_at DESC)

═══════════════════════════════════════════════════════════════════════════════
4. CHUNKS TABLE (Document Embeddings)
═══════════════════════════════════════════════════════════════════════════════
chunks
├── id (UUID) PRIMARY KEY
├── document_id (UUID) NOT NULL → REFERENCES documents(id) ON DELETE CASCADE
├── chunk_index (INTEGER) NOT NULL
├── content (TEXT) NOT NULL
├── page_number (INTEGER)
├── token_count (INTEGER)
├── vector_id (VARCHAR(255))
└── created_at (TIMESTAMP) NOT NULL

Indexes:
- idx_chunks_document ON (document_id)
- idx_chunks_vector_id ON (vector_id)

═══════════════════════════════════════════════════════════════════════════════
5. CONVERSATIONS TABLE (Chat Sessions)
═══════════════════════════════════════════════════════════════════════════════
conversations
├── id (UUID) PRIMARY KEY
├── user_id (UUID) NOT NULL → REFERENCES users(id) ON DELETE CASCADE
├── title (VARCHAR(255))
├── created_at (TIMESTAMP) NOT NULL
└── updated_at (TIMESTAMP) NOT NULL

Indexes:
- idx_conversations_user ON (user_id)
- idx_conversations_created_at ON (created_at DESC)

═══════════════════════════════════════════════════════════════════════════════
6. MESSAGES TABLE (Chat Messages)
═══════════════════════════════════════════════════════════════════════════════
messages
├── id (UUID) PRIMARY KEY
├── conversation_id (UUID) NOT NULL → REFERENCES conversations(id) ON DELETE CASCADE
├── sender (VARCHAR(50)) NOT NULL CHECK IN ('USER', 'ASSISTANT')
├── content (TEXT) NOT NULL
└── created_at (TIMESTAMP) NOT NULL

Indexes:
- idx_messages_conversation ON (conversation_id)
- idx_messages_created_at ON (created_at DESC)

═══════════════════════════════════════════════════════════════════════════════
7. MESSAGE_SOURCES TABLE (RAG Citations - Links Messages to Document Chunks)
═══════════════════════════════════════════════════════════════════════════════
message_sources
├── id (UUID) PRIMARY KEY
├── message_id (UUID) NOT NULL → REFERENCES messages(id) ON DELETE CASCADE
├── chunk_id (UUID) NOT NULL → REFERENCES chunks(id) ON DELETE CASCADE
├── relevance_score (FLOAT)
├── created_at (TIMESTAMP) NOT NULL
└── UNIQUE(message_id, chunk_id)

Indexes:
- idx_message_sources_message ON (message_id)
- idx_message_sources_chunk ON (chunk_id)
- idx_message_sources_score ON (relevance_score DESC)

FOREIGN KEY RELATIONSHIPS
═══════════════════════════════════════════════════════════════════════════════

2. documents.user_id            → users.id (ON DELETE CASCADE)
3. chunks.document_id           → documents.id (ON DELETE CASCADE)
4. conversations.user_id        → users.id (ON DELETE CASCADE)
5. messages.conversation_id     → conversations.id (ON DELETE CASCADE)
6. message_sources.message_id   → messages.id (ON DELETE CASCADE)
7. message_sources.chunk_id     → chunks.id (ON DELETE CASCADE)

═══════════════════════════════════════════════════════════════════════════════
DATA FLOW - RAG SYSTEM
═══════════════════════════════════════════════════════════════════════════════

1. USER UPLOADS DOCUMENT
   └─> documents table (status: PROCESSING)
       └─> chunks table (content split into chunks)
           └─> vector_id (stored in Pinecone/Qdrant)

2. USER STARTS CONVERSATION
   └─> conversations table
       └─> messages table (USER message)

3. SYSTEM GENERATES RESPONSE (RAG)
   a. Query vector database with user message
   b. Retrieve relevant chunks
   c. Generate response using LLM + context
   d. Store ASSISTANT message in messages table
   e. Link sources in message_sources table
      └─> message_id + chunk_id + relevance_score

4. USER VIEWS RESPONSE WITH CITATIONS
   └─> Frontend displays message with source chunks
       └─> Shows which documents/pages were used
